# Shantubag Agro Tourism Portal

## 📌 Project Overview

Shantubag Agro Tourism Portal is a web-based tourism management and booking system developed to provide users with an easy platform to explore agro-tourism facilities, view rooms and packages, make bookings, and provide feedback.

The system also provides an admin dashboard for managing bookings, rooms, packages, payments, facilities, gallery, feedback and other activities.

## 🚀 Features

### 👤 User Features

- User Registration and Login
- View Rooms and Packages
- Room Booking
- Package Booking
- Online Booking Management
- Payment Details
- Receipt Upload
- Booking Status Tracking
- Feedback Submission
- Contact Us

### 🔐 Admin Features

- Admin Login
- Dashboard
- Manage Users
- Manage Rooms
- Manage Packages
- Manage Facilities
- Manage Gallery
- Manage Bookings
- Manage Payments
- Manage Feedback
- Manage Contact Messages
- Booking Reports

## 🛠️ Technologies Used

- PHP

- HTML5
- CSS3

- XAMPP

## 🗄️ Database

MySQL is used to store:
